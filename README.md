# NETWORKWALKS-B084-WK-1-PM1-CYBERSECURITY-LAB-SETUP

My kali Linux practical work, including IP configuration  basic Linux networking tasks, completed for learning and practice.

## Project Overview

This project demonstrates the setup and configuration of a virtual cybersecurity lab using Oracle VirtualBox and Kali Linux.

The purpose is to establish a controlled virtual environment for learning Linux networking and preparing for future cybersecurity and ethical hacking exercises.

The project covers virtual machine configuration, network setup, IP addressing, connectivity verification, and snapshot management.

## Project Objectives

- Install and configure VirtualBox.
- Set up Kali Linux as a virtual machine.
- Configure a dedicated NAT Network.
- Configure and verify Kali Linux IP settings.
- Test network connectivity and DNS resolution.
- Create a clean virtual machine snapshot.
- Document the setup process with screenshots.
- Prepare the lab for future authorized security testing.
